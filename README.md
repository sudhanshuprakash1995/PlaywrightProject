# Playwright UI & API Automation Framework

## Overview

A lightweight automation framework using Playwright for:

- UI testing (web apps)
- API testing (REST)
- Written in JavaScript/TypeScript

 Features


1. Cross-browser UI tests (Chromium, Firefox, WebKit)
2. TypeScript or JavaScript support
3. Page Object Model (POM)
4. API testing via Playwright request
5. Parallel execution, retries, HTML reports

## Setup

- [x] git clone <repo-url>
- [x] cd <repo-folder>
- [x] npm install
- [x] npx playwright install


## Run Tests

- [x] npx playwright test
